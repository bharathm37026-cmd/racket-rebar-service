# Racket Rebar Service Website
Static responsive website recreated from the supplied design image.

## Files
- index.html
- style.css
- script.js
- assets/*

## GitHub Pages
1. Create a GitHub repository named `racket-rebar-service`.
2. Upload all files in this folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your Pages URL.

Replace the phone number, email, WhatsApp link, project images and text with your real business details before publishing.
